# StellarFleet-Command

4X Space Strategy & Real-Time Fleet Battle Simulation Engine

---

## Installation

```bash
cd StellarFleet-Command
npm install
```

---

## Build

```bash
npm run build
docker build -t stellarfleet-command:latest .
```

---

## Run

```bash
npm start
docker-compose up -d
```

---

## Dependencies

- **Runtime**: Node.js Standard Library (>= 18.0.0)
- **Architecture**: Modular domain engines with zero external unverified dependencies

---

## Usage

Access the application and endpoints locally on port **4500**.

---

## Testing & Coverage

```bash
npm test
npm run test:coverage
```
